# 20 — Layout Specification (Class A)

Generated by `tools/build_layout_spec.py` from `layout/book.css`, `layout/tuning.json`, `work/palette.json`, the icon tokens in the chapter files and `21_asset_manifest.csv`. The stylesheet is the executable form of this specification; where the two differ, regenerate this file. Asset IDs refer to `21_asset_manifest.csv` and `22_asset_extraction_log.md`.

## 1. Format

| Property | Screen edition | Print edition |
|---|---|---|
| Trim size | US Letter, 8.5 x 11 in (612 x 792 pt), portrait | the same |
| Margins (top, outside, bottom, inside) | 52, 46, 50, 46 pt | the same |
| Bleed | none (full-bleed cover drawn to the trim) | 0.125 in (9 pt) on the cover and on any full-bleed panel |
| Safe area | text block 520 x 690 pt; no live text within 36 pt of the trim | the same |
| Ground | parchment `#f4f2ea` (AST palette: parchment_page_2022) | white |
| Colour | sRGB | sRGB master; convert to the printer's CMYK profile at export (palette CMYK values in §4) |
| Image resolution | 150 ppi or more at placed size | 300 ppi or more at placed size; line art 600 ppi |
| Metrics | identical in both editions: only colours differ, so both paginate alike | |

Target extent: 100 pages (QA tolerance 10%).

## 2. Grid

- Two columns of 252 pt with a 16 pt gutter; baseline (body leading) 12.2 pt. Measured line length: about 57 characters (target 50 to 70).
- One continuous flow per chapter: text runs down the left column to the foot of the page and continues at the top of the right column. No element spans the columns inside a chapter; only the last page of a chapter has balanced columns.
- Wider material is placed under the chapter banner (before the flow), at the end of the chapter (after the flow), or in a chapter set as one wide column (`ref_chapters` in the tuning file). The chapter intro (60 words or fewer) sits under the banner at a 400 pt measure.
- Every chapter and appendix starts a new page. The Introduction is set in one column at a 392 pt measure.
- Headings keep with the text that follows; a heading and a short block after it are bound together so that no heading is stranded at a column foot.

## 7. Tables

- Header row reversed (parchment on `#231f20`), Cinzel capitals; alternate rows banded with a 5% ink tint; hairline rule under every row.
- Numeric cells centred; the first (label) column is never hyphenated.
- Rows never split. A table of nine rows or fewer stays whole. A longer table may break between rows; its header row repeats, and no single row is left alone on either side of the break.
- Tables sit inside a column. A table too wide for a column belongs to a chapter listed under `ref_chapters`, which is set as one wide column with running text capped at 430 pt.

## 8. Examples, definitions, and call-outs

- A worked example is a tinted box with a gold left rule and the label EXAMPLE in the display face; it follows the rule it illustrates and is kept whole when shorter than about 430 characters.
- A definition is a paragraph with a bold run-in headword; the same form is used in the Glossary, where each entry is an anchor.
- Optional rules open with the fixed three-sentence formula and carry no box.
- Numbered procedures hang their numbers in the margin of the column; sub-steps are numbered 4.1, 4.2 and indented.

## 9. Cross-references and notes

- Every "(see §N.M)" is a link to its section; the section sign and number are set in cross-reference ink. A cited sub-section title links to the section that contains it.
- Italic keywords link to their Glossary entries.
- The book has no footnotes. A note to a table is a sentence set directly after the table.

## 10. Front and back matter

1. Cover (full bleed).
2. Foreword, with the colophon at the foot of the page.
3. Contents: three columns, chapter rows in the display face with hanging numbers, section rows beneath, page numbers on dotted leaders in a reserved right gutter.
4. Chapters 1 to 20.
5. Glossary (chapter 21) and F.A.Q. (chapter 22), in the two-column flow at 8.5 pt.
6. Appendix A and Appendix B.
7. Icon reference page.

There is no separate index: the Glossary entries cite their owning sections, and every keyword in the text links to its entry.
