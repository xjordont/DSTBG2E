### CH-10-004 · §10.1 Turn Order
- Type: clarification

### CH-10-010 · §10.1 Turn Order
- Type: clarification
- Before: "*Rest*: Restore all of the character's stamina, if no *run* action was taken this turn."

### CH-10-035 · §10.5 Stat Scaling
- Type: mechanical change
- Before: "If the character's current stat value exceeds an equipment's highest stat requirement by ten or more points"
