# Issues — chapter 06 (Setup)

- B-023 (approved PROPOSED) caps shop stocking at twelve draws. With a twelve-card quota the cap would leave the shop short on nearly every stocking, and it alters the preserved category-quota mechanic outside the five signed-off changes; only its deck-exhaustion rule is applied (§6.3). The author must confirm whether the cap is wanted.
- Fog gate timing before the mega-boss: CMP-0012 (e) places the fog gate on the Level 4 doorway at board placement; A-095 and D-014 (both OPTIONAL) place it only when the board is flipped to its mega-boss side. The chapter follows A-095/D-014 because the fog gate marks a boss entrance and its shortcut rule (§15.1) would otherwise trigger on the Level 4 encounter. Confirm.
- First-leg tile layout: A-088 and C-090 (two-by-three grid, bonfire and mini-boss tile in opposite corners) and D-031 (straight line) disagree. The chapter uses the grid for the first leg and the manuscript's straight line for the second leg (§6.6), where the joined boss tiles make a line the natural shape. Confirm.
- One character per player (§6.1) follows the Introduction draft; the manuscript's "character dashboard(s)" permitted one player to control several characters. If several characters per player are intended, §6.1 and §1 both change (enemy scaling and sparks are already keyed to the number of characters, not players).
- Cross-chapter dependencies: §4.1 must define a shield as "a weapon card that shows a block or resist value and has no attack option" (B-022, D-006), the test used for stocking in §6.3; A-069's alternative test ("shield icon") was not used. §12.2 must own invader token placement and the one-invasion-per-leg rule (A-045, OQ-28), which §6.5 and §6.6 only cite. §7.7 must state that pre-dealt treasure is the reward (OQ-11) and how a single contested card, including the Level 4 mega-boss treasure card, is awarded (OQ-29). §18.1 must own campaign Level 4 placement (A-094) and the non-final mega-boss (A-049). §18.6 and §4.4 must agree that no ember card enters a shop after setup (A-046).
- Glossary: the ADD lines for Boss treasure, Treasure card, Stat cube, Hollow cube, Health dial, Invader token, and Mega-boss game board repeat chapter 02's delta verbatim so that `integrate_chapter.py` merges them idempotently whichever chapter is integrated first.
- Two clarifications have no manuscript source and should be confirmed: the party chooses which side of each encounter tile is face up at the first layout (§6.5), and ember cards and unselected boss treasure not placed at setup are returned to the game box (§6.2, §6.3).
- Sold boss treasure: §11.4 must say where a sold boss treasure card goes, since §6.2 states only that boss treasure is not shuffled into a deck at setup.
