# Issues — chapter 03 (Characters)

- Parry slot (§3.2, §9.6): the glossary (Parry, Riposte) requires the shield in the left weapon slot and the riposte weapon in the right, while A-068's approved fix allows the shield in either weapon slot with the riposte weapon in the other. §3.2 names the two slots and says only that which slot holds the shield matters (see §9.6); §9.6 must settle the rule, and the §3.2 sentence and the glossary entries must then match it.
- Stat tier four (§3.3): the red cube that replaces the stat cube at stat tier four is not a separate component in §2.8; the chapter takes it from the red (damage) cubes. The author must confirm. §11.3 and §18.6 must cite §3.3 for the tier four value (max of 40 and tier three plus five) rather than restate it.
- Luck (§3.5): the manuscript's "reroll any attack or defence roll" is drafted as one of the character's own rolls, following the fact source. If the author intended a character to spend luck on another character's roll (or on an opponent's roll in PvP, §20), §3.5 and the glossary need widening.
- Ember token sides (§3.5): CMP-0001 says every character token has a ready side and a used side; §2.8 and this chapter treat the ember token as a marker with no ready side, because it is never flipped. The author must confirm the printed token.
- "Taunt Level" (§3.1 and glossary Threat): one bridge to the label printed on the physical dashboard is kept so that readers can find the value (A-125, preserve list D-039). If the terminology rule "never taunt" is absolute, delete that one clause.
- Numerals: the bar's capacity is written "10 spaces" under the brief's digits-from-10 rule, while the reconciled glossary (Endurance bar) writes "ten-space". The glossary owner must align one way or the other.
- Cross-chapter dependencies: §6.1 must place the stat cubes in the base spaces, the three ready-side tokens in their slots, and the ember token beside the dashboard (not in the token supply; A-052 is superseded by CMP-0001). §7.2 must own hollow cube placement and removal and the death-on-full-bar consequence. §7.5, Encounter Recovery must state that the heroic action, luck, and estus flask tokens are not readied on a clear. §10.1 must own stamina overflow (stagger, never chosen), the Equip minor action, the Drink Estus major action, and the one-stamina recovery at the start of the turn. §4.1 must define a shield (B-022) and §4.3 must state that spell cards occupy a weapon slot or a catalyst, as §3.2 now asserts in one sentence each.
