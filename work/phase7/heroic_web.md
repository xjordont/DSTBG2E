# Heroic actions of the six Characters Expansion classes (web research, second pass)

Status: PARTIAL. Verbatim 2017/2018 board text found for Mercenary and Sorcerer only (one source, the community Google Doc). Nothing for 2017 Cleric, Deprived, Pyromancer, Thief.

Source key
- [UG] "DSBG - Unofficial Guide & Rules FAQ" Google Doc, https://docs.google.com/document/d/1DmbTaM68OoosZcSCFW0bTNgBWCaHSP2UE9Um-X4XF54/mobilebasic . I downloaded the full page (about 88k characters of text, saved under scratchpad/heroic/ug/) and read the heroic-ability block (text lines ~5000-5070). It labels each ability with the class and "Heroic Ability" and gives two texts: the first is the V1 (2017 board) text, the second is the V2 (2022) text. It transcribes only Sorcerer, Mercenary and Warrior; there is no Cleric, Deprived, Pyromancer, Thief or Knight/Assassin/Herald entry.
- [TSC] https://steamforged.com/cdn/shop/files/DS-TSC-Rulebook-download-min.pdf (official 2022 Sunless City rulebook), [TG] https://cdn.shopify.com/s/files/1/0602/0156/6449/files/DS-TG-Rulebook-Compressed_compressed.pdf (official 2022 Tomb of Giants rulebook). The 2022 texts below for Pyromancer, Cleric and Thief are taken from the earlier pass (classes_web.md section 4); I did not re-extract them in this pass.
- [GUG] https://www.geeksundergrace.com/tabletop/review-expansions-for-dark-souls-the-board-game/ (paraphrase, from the earlier pass).

## Results per class

### Mercenary
- Name: Rapid Strike
- Text (2017/2018 board, per [UG] "V1"): "Once per spark during their activation, the Mercenary may make an attack that costs 0 Stamina even if they already used that Weapon during their activation."
- Edition: 2017/2018 board (V1) as labelled by [UG]. 2022 text from the same source (V2): "This character makes an attack with one of their weapons. This attack costs 0 stamina."
- Sources: [UG]. Partial paraphrase support: [GUG] ("a free second attack once per spark"), which agrees in substance only.
- Independent agreement: no verbatim second source. [UG] is a single community transcription.
- Confidence: medium-high. The text is specific, internally consistent with the V2 text and the "once per spark" wording of the other V1 texts, but it is one unofficial transcription of the board.

### Sorcerer
- Name: Spell Fury
- Text (2017/2018 board, per [UG] "V1"): "Once per spark when the Sorcerer makes a magic attack, it gains infinite range and its Stamina cost is reduced by 3."
- Edition: 2017/2018 board (V1). 2022 text from [UG] (V2): "This character's next attack with the magic symbol gains infinite range and costs 0 stamina."
- Sources: [UG]. Paraphrase support: [GUG] ("once-per-spark use of an unlimited range spell for -3 stamina"), which agrees in substance (infinite range, -3 stamina).
- Independent agreement: partial (paraphrase only).
- Confidence: medium-high. Same reasoning as Mercenary; the -3 stamina detail is confirmed by a separate review.

### Pyromancer
- Name: Explosive Firepower (2022 name). 2017 name not found.
- Text: 2017/2018 board text NOT FOUND. 2022 board (official [TSC] and [TG], both identical): "This character's next attack with the [magic symbol] gains an additional [dice icon]." (icons did not survive text extraction in the PDFs; I could not tell which die colour.)
- Edition: 2022 only. 2017 board wording unknown and may differ (the other classes' 2017 texts are longer and use "Once per spark ...").
- Sources: [TSC], [TG]. [GUG] mentions only a "once-per-spark spell buff".
- Independent agreement: the two 2022 rulebooks agree with each other but are the same publisher and same edition, so they are not independent for the 2017 question.
- Confidence: high for the 2022 text, none for the 2017 text.

### Cleric
- Name: Keep the Faith (2022 name). 2017 name not found.
- Text: 2017/2018 text NOT FOUND. 2022 board (official [TG]): "This character and each other character on the same or an adjacent node heals 2 damage."
- Edition: 2022 only.
- Sources: [TG] (and the Painted World/Tomb of Giants rulespal page https://rulespal.com/dark-souls-the-board-game-tomb-of-giants/rulebook lists the Cleric, but I did not get dashboard text from it).
- Independent agreement: no.
- Confidence: high for the 2022 text, none for the 2017 text. The 2017 Cleric is described only as a team player "because of her healing spell" ([GUG]).

### Thief
- Name: Lucky Break (2022 name). 2017 name not found.
- Text: 2017/2018 text NOT FOUND. 2022 board (official [TG]): "This character heals 2 damage and recovers 2 stamina, then flip their luck token to the ready side."
- Edition: 2022 only.
- Sources: [TG]. [GUG] says the 2017 Thief "can heal 2 stamina and 2 health", which is consistent with the 2022 effect (heal 2 and recover 2 stamina) but is a paraphrase of unclear scope; it suggests the 2017 effect may be the same minus the luck-token part, but that is inference.
- Independent agreement: no.
- Confidence: high for the 2022 text, none for the 2017 text.

### Deprived
- Name: not found.
- Text: NOT FOUND for either edition.
- Edition: unknown.
- Sources: none. [UG] mentions the Deprived only for transposed treasure and component tables, not for a heroic ability. The 2022 Painted World rulebook (Deprived/Mercenary/Sorcerer) could not be obtained as text (see below).
- Independent agreement: no.
- Confidence: none.

## Core-class cross-check (not a ten-class list)
No source listing all ten classes together was found. [UG] gives full V1/V2 text for Warrior (Berserk Charge) as well: V1 "Once per spark during his activation, the Warrior may move one node without spending stamina. The next range 0 attack he makes costs 0 stamina and gains [node attack]." V2 "This character's next attack gains [node attack] and does not cost stamina. Before making the attack, they can be placed in an adjacent node." This replaces the earlier summarised remainder in classes_web.md with a read-in-full version. The dicenboard.com guide (https://dicenboard.com/game-guides/dark-souls-board-game/) covers only the four core classes, in paraphrase (Knight "Stand Fast", Warrior "Berserk Charge", Herald "Perseverance", Assassin "Backstab"); note it names the Herald's action Perseverance, not "Rapport".

## What I could not find, and what I tried
- 2017/2018 board images: BoardGameGeek's image API (api.geekdo.com/api/images) works from here. I listed the galleries of the Characters Expansion (object 285975) and the core game (197831) and checked the images captioned Thief, Sorcerer, Pyromancer, Mercenary, Deprived, Cleric: they are painted miniatures, not boards. No gallery image captioned as a character board/dashboard for these classes turned up by caption search (I did not open every image).
- BGG forums: scanned about 394 thread subjects for both games and the first page of articles in each; none mentioned a heroic action together with one of the six classes.
- BGG files: listed; likely candidates (DS-Extended-Rules-V27.pdf, Hollowed Edition v1.3.pdf, Rules Summary) require login to download, so I could not read them. They may contain class texts, unverified.
- Fextralife Dark Souls board game wiki (darksoulstheboardgame.wiki.fextralife.com): host resolves but the egress proxy cannot connect (connect_unreachable). Appears in search results for "Player Characters", so it may carry the text; it is the best remaining lead if access can be arranged.
- Fandom wiki: 403. github.com pages: 403, GitHub MCP/API access to DanDuhon/DSBG-Shuffle is not enabled. raw.githubusercontent.com works, but the repo is an enemy/encounter shuffler (README, local characters file) and has no heroic-action data.
- Reddit: blocked for the search tool and 403 via curl; redlib mirror had a TLS problem.
- Steamforged site: Painted World product page 404 at the guessed URL; no rulebook link found. rulespal.com Painted World page returned only a stub (no dashboard text).
- Steam Workshop TTS mod page: only a fan "Deprived" discussion, no heroic text.
- Searches in English, French and German for class heroic actions returned only retail listings and the rulebooks already known. The Characters Expansion rules PDFs (gamers-hq.de DS-Characters-Rules, 1j1ju) contain only component lists, as stated in the earlier pass.
- Not attempted/limited: the Google Doc was read in full but contains no Cleric, Deprived, Pyromancer or Thief ability text in any version.

## Bottom line
- Usable as 2017 board text (medium-high): Mercenary "Rapid Strike", Sorcerer "Spell Fury", both from [UG] V1.
- 2022 text only (do not use as 2017): Pyromancer "Explosive Firepower", Cleric "Keep the Faith", Thief "Lucky Break".
- Unknown: Deprived (both editions); 2017 names/texts for Pyromancer, Cleric, Thief.
